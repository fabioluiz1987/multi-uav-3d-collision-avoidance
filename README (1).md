# Decentralized 3D UAV Collision Avoidance with Modified APF

This repository contains the simulation files, experiment data, figures, and supplementary videos associated with the article:

**A Decentralized 3D Collision Avoidance Algorithm for Multi-UAV Systems Based on Modified Artificial Potential Fields**

The work proposes a decentralized three-dimensional collision avoidance algorithm for multi-UAV systems. The method combines global path planning with **A\*** and local reactive navigation using a modified **Artificial Potential Field (APF)** formulation. Each UAV computes its own motion locally, using only limited shared information from nearby UAVs, such as current position, operational state, and a window of future waypoints.

## Overview

The proposed algorithm is designed for multi-UAV systems operating in a shared 3D environment. Its main goal is to preserve safe separation between UAVs while allowing each vehicle to follow a planned global trajectory.

The method includes:

- **Global path planning with A\*** for generating the reference route of each UAV.
- **Local trajectory adjustment with modified APF**, combining attraction to the planned route and repulsion from neighboring UAVs.
- **Predictive avoidance**, using future waypoint information shared by other UAVs.
- **Emergency-aware behavior**, where UAVs in emergency state receive operational priority.
- **Decentralized execution**, where each UAV computes its own motion without a central controller.
- **Influence radius**, limiting interactions to nearby UAVs and future waypoints.
- **Adaptive waypoint visitation**, allowing more flexible route following during conflicts.
- **Random perturbation**, used to reduce local equilibrium and symmetry-related deadlocks.

## Basic Algorithm Operation

At each simulation step, every UAV performs the following operations:

1. Measures or estimates its current position.
2. Shares its current position, operational state, and future waypoints.
3. Receives the same information from neighboring UAVs.
4. Filters UAVs and future waypoints outside the influence radius.
5. Computes the attraction force toward its own future waypoints.
6. Computes repulsive forces from nearby UAVs.
7. Computes repulsive forces from future waypoints of other UAVs.
8. Applies state-dependent interaction rules for normal and emergency UAVs.
9. Adds damping and, when necessary, a small random perturbation.
10. Updates velocity and position under the imposed kinematic limits.
11. Marks reached waypoints as visited.
12. Repeats the process until the UAV reaches its final waypoint.

## Emergency-State Interaction Logic

The emergency-state logic is one of the main features of the proposed method:

- Normal UAVs avoid both normal and emergency UAVs.
- Emergency UAVs keep priority and do not react to normal UAVs.
- Emergency UAVs still avoid other emergency UAVs.
- Normal UAVs also avoid the future trajectory of emergency UAVs.

This behavior allows a UAV in emergency state to continue along a priority route while the remaining UAVs adjust their trajectories to preserve safety.

## Evaluation Metrics

The simulations record safety and trajectory-quality metrics, including:

- Minimum inter-UAV distance.
- Collision detection based on a predefined collision threshold.
- Mean lateral error relative to the planned trajectory.
- Lateral RMSE relative to the planned trajectory.
- Maximum path deviation.
- Trajectory elongation index.
- Success rate over repeated simulations.
- Collision rate over repeated simulations.

For statistical evaluation, scenarios can be executed multiple times using different random seeds. The resulting CSV files can be used to compute mean, standard deviation, variance, median, minimum, and maximum values for each metric.

## Running Simulations

A typical non-visual simulation run can be executed as:

```bash
python src/anticolisao_3D_superficie_curva.py \
  --modo_visual 0 \
  --cenario 1 \
  --run_id 1 \
  --seed 1001 \
  --saida results/resultado_global.csv
```

For statistical evaluation, run the same scenario multiple times using different seeds and aggregate the results in a single CSV file.
